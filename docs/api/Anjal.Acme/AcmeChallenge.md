# AcmeChallenge

**Namespace:** `Anjal.Acme`

An HTTP-01 challenge inside an authorization.

## Members

- **Error** *(property)* - Error detail if invalid.
- **Status** *(property)* - pending, processing, valid or invalid.
- **Token** *(property)* - Token.
- **Type** *(property)* - Challenge type, e.g. http-01.
- **Url** *(property)* - Challenge URL.
