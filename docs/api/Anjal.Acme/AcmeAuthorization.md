# AcmeAuthorization

**Namespace:** `Anjal.Acme`

An authorization (RFC 8555 §7.1.4).

## Members

- **Challenges** *(property)* - Challenges offered.
- **Identifier** *(property)* - The DNS identifier.
- **Status** *(property)* - pending, valid, invalid, expired, revoked or deactivated.
- **Url** *(property)* - Authorization URL.
