# CertificateMetadata

**Namespace:** `Anjal.Acme`

Metadata saved next to the certificate files.

## Members

- **DirectoryUrl** *(property)* - ACME directory the certificate came from.
- **Domains** *(property)* - Domains in the certificate.
- **ExpiresAt** *(property)* - NotAfter of the leaf (UTC).
- **IssuedAt** *(property)* - When issued (UTC).
- **KeyType** *(property)* - Key type used.
