# ModuleInfo

**Namespace:** `Anjal.Dkim`

RFC 6376 DKIM signing. Implements both simple and relaxed canonicalization for headers and body. Signing is RSA-SHA256 only (Ed25519 deferred until .NET BCL ships System.Security.Cryptography.Ed25519). Zero NuGet dependencies; uses System.Security.Cryptography from the BCL.

## Members

- **Name** *(field)* - Module name as it appears in logs and diagnostics.
