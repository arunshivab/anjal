# Program

**Namespace:** `Anjal.BreakGlass`

rc.25 (DES-15 §6.3, D-240, D-241, OPS-16): Anjal's break-glass key, on an offline computer only. make - make the key: prints the line for the server's settings and the three paper shares. check - the yearly drill: two shares rebuild the key, and it matches the line. open - on an organisation's written request: two shares open that organisation's sealed recovery secret, printed as its recovery sheet. Secrets are typed in when asked, never on the command line, so they stay out of the shell's history.
