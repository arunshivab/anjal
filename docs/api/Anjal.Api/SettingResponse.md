# SettingResponse

**Namespace:** `Anjal.Api.Dto`

One stored setting.

## Members

- **Key** *(property)* - The setting's name.
- **Scope** *(property)* - "server" or "webmail".
- **UpdatedAt** *(property)* - When it was last changed.
- **UpdatedBy** *(property)* - "import" for the one-time import, "api" for a change through this API.
- **Value** *(property)* - The stored value.
