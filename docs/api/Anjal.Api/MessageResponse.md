# MessageResponse

**Namespace:** `Anjal.Api.Dto`

Response body for one message's metadata (no body).

## Members

- **Answered** *(property)* - Replied to.
- **Date** *(property)* - Raw Date header.
- **EnvelopeFrom** *(property)* - SMTP envelope MAIL FROM.
- **Flagged** *(property)* - Flagged/starred.
- **FolderId** *(property)* - The folder's id.
- **From** *(property)* - Raw From header.
- **Id** *(property)* - Identifier assigned by the store.
- **MailboxId** *(property)* - The owning mailbox's id.
- **MessageId** *(property)* - Message-ID header without angle brackets.
- **ReceivedAt** *(property)* - When the message was delivered.
- **Seen** *(property)* - Read flag.
- **SizeBytes** *(property)* - Size in bytes.
- **SpamScore** *(property)* - Spam score assigned at delivery.
- **Subject** *(property)* - Decoded Subject header.
- **To** *(property)* - Raw To header.
