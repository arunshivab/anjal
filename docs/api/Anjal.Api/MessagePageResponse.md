# MessagePageResponse

**Namespace:** `Anjal.Api.Dto`

Response body for a page of messages.

## Members

- **Items** *(property)* - The messages in this page, newest first.
- **Limit** *(property)* - The page size requested.
- **Offset** *(property)* - The offset this page started at.
- **Total** *(property)* - Total messages matching the query (all pages).
