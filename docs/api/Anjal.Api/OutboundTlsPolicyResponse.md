# OutboundTlsPolicyResponse

**Namespace:** `Anjal.Api.Dto`

Response body for outbound TLS policy operations.

## Members

- **Domain** *(property)* - The destination domain.
- **Id** *(property)* - Identifier assigned by the store.
- **Mode** *(property)* - Effective TLS mode ("opportunistic", "required", "disabled").
- **UpdatedAt** *(property)* - When the policy was created or last updated.
