# PagePick

**Namespace:** `Anjal.Viewing`

One page of the result: which file and page it comes from, and the turn added to it.

## Members

- **File** *(property)* - The file: 0 is the one being edited, 1 and on the joined PDFs.
- **Page** *(property)* - The page in that file (0-based).
- **Turn** *(property)* - The turn added, clockwise: 0, 90, 180 or 270.
