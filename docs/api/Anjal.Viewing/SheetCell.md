# SheetCell

**Namespace:** `Anjal.Viewing`

One cell: its column (1-based), what it shows (the file's own format), and its stored value.

## Members

- **C** *(property)* - The column.
- **D** *(property)* - What it shows.
- **V** *(property)* - Its stored value, when that differs from what it shows.
