# RedactedPage

**Namespace:** `Anjal.Viewing`

What the redaction removed on one page.

## Members

- **Characters** *(property)* - Characters of text removed.
- **Drawings** *(property)* - Drawn lines and shapes removed whole or in part.
- **FormValues** *(property)* - Values of form fields cleared.
- **Page** *(property)* - The page, 0-based, in the file as saved.
- **Pictures** *(property)* - Pictures removed whole or in part.
