# TextRun

**Namespace:** `Anjal.Viewing`

One run of text on a shown page: its baseline's start (from the top-left, in points), its size, its turn (degrees clockwise on the screen) and its width (0 when the file does not say).

## Members

- **A** *(property)* - The turn, degrees clockwise.
- **S** *(property)* - The font size.
- **T** *(property)* - The text.
- **W** *(property)* - The width along the baseline; 0 when unknown.
- **X** *(property)* - The baseline's start, from the left.
- **Y** *(property)* - The baseline's start, from the top.
