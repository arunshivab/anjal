# NumberSpec

**Namespace:** `Anjal.Viewing`

Page numbers, or a header or footer line, on every page (§7.7, D-376).

## Members

- **Format** *(property)* - The words, with {n} for the page's number and {N} for how many there are.
- **Size** *(property)* - The size of its letters, in points.
- **Start** *(property)* - The number of the first page.
- **Where** *(property)* - Where ().
