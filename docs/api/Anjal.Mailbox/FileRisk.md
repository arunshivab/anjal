# FileRisk

**Namespace:** `Anjal.Mailbox`

What Anjal says about a file it delivers but cannot fully vouch for (rc.24, item 93, D-196).

## Members

- **Encrypted** *(field)* - An encrypted archive (or a password-protected Office file): no scanner can look inside.
- **Macros** *(field)* - An Office file with macros: small programs that run when the file is opened.
- **None** *(field)* - Nothing to say.
