# ReconstructionReport

**Namespace:** `Anjal.Mailbox`

The result of reconstruction.

## Members

- **AlreadyKept** *(property)* - Messages that already have evidence.
- **Applied** *(property)* - Whether copies were made (false: dry run).
- **Candidates** *(property)* - Messages without evidence.
- **Created** *(property)* - Reconstructed copies made.
- **Unreadable** *(property)* - Messages whose file could not be read.
