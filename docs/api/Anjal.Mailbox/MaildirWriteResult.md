# MaildirWriteResult

**Namespace:** `Anjal.Mailbox`

Result of writing one message into a Maildir folder.

## Members

- **FullPath** *(property)* - Absolute path of the written file.
- **RelativePath** *(property)* - Path of the written file relative to the folder's Maildir directory (e.g. new/1726560000.M1P42Q7.host).
- **SizeBytes** *(property)* - Size of the written file in bytes.
