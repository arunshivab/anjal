# AliasEntry

**Namespace:** `Anjal.Mailbox`

An extra address that delivers to a person's own mailbox (rc.22, item 41).

## Members

- **Address** *(property)* - The address, lower case, on one of the organisation's domains.
- **CanSend** *(property)* - Whether the person may also send from it.
- **MailboxId** *(property)* - The mailbox it delivers to.
