# LabelRecoveryReport

**Namespace:** `Anjal.Mailbox`

The result of label recovery.

## Members

- **AlreadyCorrect** *(property)* - Messages whose record was already right.
- **Applied** *(property)* - Whether changes were applied (false: dry run).
- **Changes** *(property)* - The changes (made, or that would be made).
- **Checked** *(property)* - Messages examined.
- **NoReceivedLine** *(property)* - Messages with no Received line from this server (created here).
- **Unreadable** *(property)* - Messages whose file could not be read.
