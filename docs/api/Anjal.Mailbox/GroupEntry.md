# GroupEntry

**Namespace:** `Anjal.Mailbox`

One address that reaches several people, each in their own Inbox (rc.22, item 41).

## Members

- **Address** *(property)* - The address, lower case.
- **Members** *(property)* - The members' mailboxes.
- **OrgOnly** *(property)* - True when only the organisation's own people may write to it; mail from outside is refused.
