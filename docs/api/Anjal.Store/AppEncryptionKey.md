# AppEncryptionKey

**Namespace:** `Anjal.Store`

An application's public encryption key (DES-14 §18), as the organisation's "apps" document keeps it.

## Members

- **Added** *(property)* - When it was added.
- **Fingerprint** *(property)* - Its fingerprint: the hex SHA-256 of its DER form.
- **Pem** *(property)* - The public key, PEM.
