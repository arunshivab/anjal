# AppInboxAddress

**Namespace:** `Anjal.Store`

rc.26 (DES-14 §13): an application's inbox address.

## Members

- **AddedAt** *(property)* - When it was added.
- **Address** *(property)* - The address, lower case.
- **AppId** *(property)* - The application.
- **MailboxId** *(property)* - The application's hidden mailbox.
- **SharedMailboxId** *(property)* - The mailbox that already held the address and keeps receiving it (D-227), or null.
- **TenantId** *(property)* - The organisation.
