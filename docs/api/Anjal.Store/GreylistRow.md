# GreylistRow

**Namespace:** `Anjal.Store`

One remembered greylisting triplet.

## Members

- **FirstSeen** *(property)* - When the triplet was first seen.
- **Key** *(property)* - The triplet key: client network, sender and recipient.
- **LastSeen** *(property)* - When the triplet was last seen.
- **Passed** *(property)* - Whether a retry has passed, so the sender is no longer delayed.
