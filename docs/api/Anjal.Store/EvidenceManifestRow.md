# EvidenceManifestRow

**Namespace:** `Anjal.Store`

One day's manifest in the evidence chain.

## Members

- **Added** *(property)* - Copies added that day.
- **Day** *(property)* - The day it covers (UTC).
- **Path** *(property)* - Path under the evidence root.
- **PreviousSha256** *(property)* - SHA-256 of the previous day's manifest (64 zeros for the first).
- **Purged** *(property)* - Copies purged that day.
- **Sha256** *(property)* - SHA-256 of the manifest file.
