# ChatRoomRow

**Namespace:** `Anjal.Store`

rc.28 (DES-21 §5): a chat - with one colleague, or a named group.

## Members

- **CreatedAt** *(property)* - When.
- **CreatedBy** *(property)* - Who started it.
- **Id** *(property)* - Its id.
- **IsGroup** *(property)* - True for a group.
- **LastMessageAt** *(property)* - When its last message was written (its place in the list).
- **Name** *(property)* - A group's name; empty for a chat with one colleague.
- **TenantId** *(property)* - The organisation.
