# SealRecord

**Namespace:** `Anjal.Store`

What is published about the mail server's seal key (DES-11 S6).

## Members

- **Made** *(property)* - When this seal key was made or first published.
- **Path** *(property)* - Where its private half is kept on the mail server.
- **PublicKey** *(property)* - The public key, SubjectPublicKeyInfo DER, base64.
