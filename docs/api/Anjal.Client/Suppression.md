# Suppression

**Namespace:** `Anjal.Client`

An address on the do-not-send list (DES-14 §19).

## Members

- **Address** *(property)* - The address.
- **At** *(property)* - When it was added.
- **Note** *(property)* - The reason in words.
- **Reason** *(property)* - hard_bounce, complaint, unsubscribe or manual.
- **SendId** *(property)* - The send that caused it, or null.
- **Suppressed** *(property)* - For a single lookup: whether it is suppressed.
