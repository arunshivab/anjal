# DecryptedMail

**Namespace:** `Anjal.Client`

A mail of the application's inbox, decrypted and read (DES-14 §14).

## Members

- **Attachments** *(property)* - The files.
- **Cc** *(property)* - Cc.
- **From** *(property)* - From.
- **Headers** *(property)* - Its headers, each name with its values in order.
- **Html** *(property)* - The HTML part.
- **Raw** *(property)* - The mail exactly as it arrived.
- **ReplyTo** *(property)* - Reply-To.
- **Risks** *(property)* - Files Anjal warns about (a locked archive, macros), from the envelope's meta.
- **Subject** *(property)* - The subject, decoded.
- **Text** *(property)* - The text part.
- **To** *(property)* - To.
