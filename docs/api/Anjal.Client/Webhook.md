# Webhook

**Namespace:** `Anjal.Client`

A webhook (DES-14 §8). The secret is given only when it is added.

## Members

- **Events** *(property)* - The event types it takes; empty for all.
- **Id** *(property)* - Its id.
- **Secret** *(property)* - The secret, when just added; null otherwise.
- **Url** *(property)* - Its address.
