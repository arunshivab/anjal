# HostLookup

**Namespace:** `Anjal.Smtp`

Whether a domain has an address (v1.0.0-rc.9, implicit MX).

## Members

- **Found** *(field)* - At least one address.
- **NotFound** *(field)* - No such host, or no address records: a permanent answer.
- **TryAgain** *(field)* - The lookup failed temporarily.
