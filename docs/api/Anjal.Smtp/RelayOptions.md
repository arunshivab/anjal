# RelayOptions

**Namespace:** `Anjal.Smtp`

Configuration for a .

## Members

- **ClientHostName** *(property)* - Hostname this client claims in EHLO.
- **ConnectTimeout** *(property)* - Connect timeout.
- **Host** *(property)* - Host of the relay (e.g. "smtp-relay.gmail.com").
- **Port** *(property)* - Port of the relay. 587 is the SMTP submission port.
- **Tls** *(property)* - TLS configuration. When null, TLS is disabled.
